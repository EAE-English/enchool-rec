# [Claude] 엔쿨 녹음 화면

- `rec.html?s=이름&k=책_과[.선택]&c=반[&me=역할]` — 녹음 숙제 (본문 읽기 · 대화문 역할극)
  - 선택: 대화문ID(`lta1`), Step(`s1`, `s1_3`), 본문(`body`), 없으면 전부
- `scripts/책_과.json` — 대본 서재 (학습관리실 책보관소에서 Claude가 만들어 올림)
- `role.html?s=이름&r=…` — 예전 쿨톡 역할극 주소 (남겨 둠)

녹음 파일은 여기 저장되지 않고, 엔쿨 학습 기록(Apps Script)을 거쳐 구글 드라이브 학생 폴더 + 「엔쿨 녹음 관리」 시트로 갑니다.
